# Life Timer

Its not as grim as it sounds, I swear. I've always found myself really struggling with time management, specifically with estimating how long something will actually take.
And as much as my phone would fix the problem by setting timers and tracking activities, it tends to distract me (by watching YouTube) more than it actually helps me...
So instead of buying a cheap timer/stopwatch on Amazon for 10$, I'm making this needlessly complicated by creating my own that keeps track of all this for me!

## Features
- Timer function (with presets)
- Stopwatch function (10ms resolution)
- Low power consumption
- Small, lightweight, and portable
- Built-in 3in1 mounting solution (stand, clip, and wall hook)
