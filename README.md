# Life Timer

Its not as grim as it sounds, I swear. I've always found myself really struggling with time management, specifically with estimating how long something will actually take.
And as much as my phone would fix the problem by setting timers and tracking activities, it tends to distract me (by watching YouTube) more than it actually helps me...
So instead of buying a cheap timer/stopwatch on Amazon for 10$, I'm creating my own that keeps track of all this for me!

## Features
- Timer function
- Stopwatch function (10ms resolution)
- Low power consumption
- Small, lightweight, and portable

## Specs

### Hardware
* ATtiny85 (SMD package)
* SSD1306 128x32 OLED Display Module
* 3x push buttons
* Piezo speaker (for alarm sounds)

### Firmware
* Custom firmware

### Software
* Arduino IDE (firmware development)
* git/GitHub (version control)
* KiCAD (schematic and PCB design)
* FreeCAD (case design and [eventually] OLED model)
